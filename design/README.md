# Исходный макет

Источник: «Приложение для отслеживания здоровья питомцев. Гармаева Елена.fig», страница lo-fi (`585:240`), секция Prototype (`2043:2697`).

`source-layout.json` содержит размеры и координаты компонентов семи кадров, прочитанные из бинарного canvas.fig. Система координат — 402×874. Иконки в `public/figma` извлечены из исходных векторных контуров; они заменяют прежние иконки Lucide.

- 1 (`2073:5885`) — пустая главная: текст y=334, кнопка x=32, y=786, 338×56. Нижней навигации на этом экране нет.
- 2 (`2127:5759`) — основная информация: фото 80×80, имя y=226, тип и пол в общей карточке y=290, порода y=410, возраст и вес y=474, чип y=538.
- 2.1 (`2128:6065`) — та же форма с документами, без отдельного шага документов.
- 3 / 3.1 — повторяющиеся карточки названия, даты, времени, повтора и напоминания. Кнопка «Сохранить» остаётся внизу.
- 4 — фото на всю ширину, блок состояния здоровья, индикатор страниц и события. Нижняя панель имеет четыре пункта и центральную кнопку.
- 4.1 — раскрытая панель добавления питомца, события и документа.

Данные пользователя заменяют значения прототипа в полях и карточках. Вкладки календаря, списка питомцев и профиля используют компоненты той же дизайн-системы; отдельных полноэкранных макетов этих вкладок в секции Prototype нет.

## Уточнение геометрии

Исходные переменные и их связи перенесены в `src/design-system/figma.tokens.json`. Раскладка карточек событий: поверхности 280 px, промежуток 8 px (y=138, 426, 714). Главная выделенная карточка целиком оранжевая, а не только её строка события. Нижняя панель использует исходный контур Subtract. Меню добавления сохраняет исходные повороты −20° / 0° / 20°. Фото отображается с исходными нормализованными преобразованиями обоих слоёв.
