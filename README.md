# Приложение для отслеживания здоровья питомцев

React + Vite. Интерфейс переработан по структуре и координатам предоставленного файла Figma. Исходные координаты экранов описаны в [design/README.md](design/README.md); оригинальные векторы находятся в `public/figma`. Применены Manrope, палитра #F26435 / #F2F2F7 / #1C1C1E / #8E8E93 и фотографии из файла.

Публичный сайт: https://helenagarmaeva.github.io/Edu/

## Запуск

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm run build
PLAYWRIGHT_BROWSERS_PATH=/tmp/pw-browsers npx playwright install chromium
PLAYWRIGHT_BROWSERS_PATH=/tmp/pw-browsers npm test
```

Тесты проверяют координаты элементов из исходного макета, сохранение питомца, документов и событий, масштабирование на 360 px и отказ хранилища.

## Хранение данных

Данные и документы сохраняются в localStorage текущего браузера. Синхронизация, сервер и отправка уведомлений не реализованы. Напоминания и периодичность сохраняются как настройки; повторные события автоматически не создаются. Очистка данных браузера удаляет записи. Максимальный размер фотографии — 5 МБ, документа — 2 МБ; итоговая ёмкость ограничена браузером.

## Публикация

`npm run build` создаёт статическую сборку в `dist/`. Сайт обслуживается GitHub Pages из корня ветки `gh-pages`. Изменения в основной ветке сами по себе не обновляют опубликованную сборку.
