# Приложение для отслеживания здоровья питомцев

Мобильное веб-приложение на React и Vite по макету Елены Гармаевой. Использованы палитра (#F26435, #F2F2F7, #1C1C1E, #8E8E93), Manrope, тексты, карточки и две оригинальные фотографии из предоставленного .fig. Иконки — Lucide, подобраны по смыслу; это адаптивная реализация, не экспорт экранов Figma.

## Запуск

```sh
cd /workspace/Edu
npm ci
npm run dev
```

## Проверки

```sh
npm run build
PLAYWRIGHT_BROWSERS_PATH=/tmp/pw-browsers npx playwright install chromium
PLAYWRIGHT_BROWSERS_PATH=/tmp/pw-browsers npm test
```

## Возможности

- Пустой главный экран, создание, редактирование и удаление питомцев.
- Фотографии из макета и загрузка собственной фотографии (до 5 МБ).
- Двухшаговое добавление питомца и загрузка документов (до 2 МБ каждый).
- События с датой, временем, типом, периодичностью и настройкой напоминания.
- Календарь с переключением месяцев, просмотром и удалением событий.
- Профиль владельца, переключение между питомцами.

Данные и файлы хранятся только в localStorage текущего браузера. Очистка данных браузера удаляет записи. Сервер, авторизация и синхронизация между устройствами не реализованы. Напоминания и периодичность сохраняются как настройки, но не отправляют уведомления и не создают повторные события автоматически. При нехватке места приложение сообщает об ошибке сохранения.
