# Дизайн-система по исходному Figma

Публичная витрина: `/?view=design-system`. Проверяемые состояния исходных кадров: `/?frame=1`, `2`, `2.1`, `3`, `3.1`, `4`, `4.1`. Демонстрационные записи не записываются в localStorage и не заменяют данные пользователя.

## Источники и уровни токенов

1. `figma.tokens.json` — 212 переменных исходного файла. Сохранены имена, коллекции, идентификаторы, режимы и алиасы. `figma.tokens.css` генерируется из этого файла, включая светлый и тёмный набор цветов. Основной интерфейс следует светлому макету.
2. `components.css` — семантические связи компонентов с токенами Figma, типографика Manrope и геометрия экранов. Например, поле использует `--size-text-field-height`, а не отдельное числовое значение. Радиус одиночного поля — `ContentField/Radius/Single → Size Primitives/32`; радиус группы — 24.
3. `layout.json` — размеры и координаты кадров 402×874; `geometry.json` — исходные преобразования фотографий и трёх пунктов раскрытого меню. Размеры, которых нет среди переменных Figma, находятся в `measured.tokens.json` / генерируемом CSS. Это измерения границ компонентов, а не новые произвольные отступы.

`src/style.css` и `gallery.css` используют переменные. Единственное размерное значение вне токенов в стилях приложения — граница медиазапроса: CSS не позволяет применять var() в условии @media.

```sh
npm run tokens        # обновить генерируемый CSS из JSON
npm run tokens:check  # проверить соответствие JSON/CSS и отсутствие неизвестных CSS-переменных
```

`npm run build` и `npm test` запускают проверку токенов автоматически.

## Компоненты

- `Button` — primary / secondary, disabled и pressed. Размеры и состояния берутся из токенов Button и Colors Semantic.
- `Surface` — групповые и одиночные поверхности.
- `TextField` — одиночное поле ввода.
- `SelectRow` — строка с подписью, значением и оригинальным шевроном.
- `DateTimeRow` — строка даты или времени с нативным вводом и независимым от языка браузера русским представлением. Доступное имя поля отделено от видимой подписи.
- `ScreenFrame` — единая система координат 402×874, пропорционально уменьшающаяся на узких экранах.
- `Icon` — исходные векторные формы Figma. Одноцветные формы получают семантические цвета через SVG-маску; многослойные исходные изображения сохраняют свои цвета.

Исходная нижняя панель использует булево вычитание окружности из поверхности. Это вырез, а не добавленная окружность. Меню добавления имеет исходные матрицы поворота, без дополнительных белых карточек.

## Проверки геометрии

Проверяются форма с документами, три карточки событий (y=138, 426, 714), главная карточка (y=510, высота 123), ближайшие события (y=641, высота 432), панель (y=770) и раскрытое меню (y=651). Проверяется также закрепление панели при прокрутке и доступность текста заголовка над светлым содержимым.

Проверки не заменяют ручную визуальную сверку. Изменяемые значения питомцев и событий закономерно отличаются от демонстрационных надписей Name / Title в файле; режимы `?frame=` позволяют сравнивать одинаковые данные.
